# idlefy-universal playground

A Vite + React + TypeScript app that lets you explore the `idlefy-universal` Helm
chart in the browser: pick or edit values, render the chart (via the WASM Helm
engine built in `playground/engine/`), and visualize the resulting resources.

## Chart bundle

`src/chart-bundle/` (gitignored) is generated by `scripts/bundle-chart.mjs` from the
repository's `charts/idlefy-universal/` chart, its `values.schema.json`, and the
`examples/` directory. It produces:

- `chart.json` — every chart file (excluding `tests/`, `ci/` and `values.schema.json`) as a `Record<string, string>`.
- `schema.json` — the chart's `values.schema.json`.
- `examples.json` — one `{ id, label, values }` entry per example under `examples/`.
- `chart-meta.json` — `{ name, version }`, read from `Chart.yaml`.

`npm run dev`, `npm run build` and `npm test` all regenerate this bundle first, so it
always reflects the current state of the chart and examples.

## Scripts

- `npm run dev` — generate the chart bundle, then start the Vite dev server.
- `npm run build` — generate the chart bundle, typecheck, then build to `dist/`.
- `npm test` — generate the chart bundle, then run the Vitest suite.
- `npm run e2e` — run Playwright end-to-end tests.
- `npm run preview` — preview a production build locally.
